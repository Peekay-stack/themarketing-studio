# Provocation: breaking a category's codes on purpose

A **provocation** is a deliberate, approved departure from how a whole category talks and looks. It is not a louder version of the usual
work, and it is not shock for its own sake. It is one specific code of the category, broken in a way the brand can stand behind.

The test of a good provocation is two sentences:

1. "Every brand in this category does X."
2. "We don't, and the reason we can is the brand's own truth."

If the second sentence cannot be written from the idea platform, it is not a provocation for this brand. It is just a different ad.

## What a category code is

A code is a habit the whole category repeats until nobody sees it. Five kinds, and a good audit names at least one of each where it exists:

- **Verbal**: the words, claims and tag-line shapes everyone uses ("pure", "goodness of", a promise followed by a proof).
- **Visual**: the look. Light, colour, props, setting, who is in the frame, how the pack is shown.
- **Tonal**: the feeling. Reassuring, hushed, aspirational, earnest, funny in the same safe way.
- **Structural**: the shape of the story. Problem then product then resolution, a child growing up, a before and after, a family around a table.
- **Sonic**: the sound. The same soft strings, the same warm voice, the same jingle logic.

A code is only worth breaking if it is **really shared** (several brands do it) and **breakable** (the brand loses nothing true by dropping it).

## Evidence and memory: say which it is

Codes come from one of two places and the person must always be able to tell which.

- **Seen**: grounded in something the person provided (a pack, an Instagram page, a social video, POSM, a TVC for a named competitor). Cite where, using the competitor's name and the channel exactly as given.
- **Memory**: from general knowledge of the category or the brands. Say so. Memory about a specific competitor's recent work is often dated or wrong; never present it as seen. When in doubt, it is memory.

Never invent something a competitor did. If the evidence is thin, say the code is a hypothesis.

## How to break a code

Pick one move and commit to it: **remove** the code (the film with no people), **invert** it (silence where there is music), **exaggerate** it until it is a joke the category cannot make about itself, **relocate** it (the same ritual somewhere unexpected), or **reframe** it (the same scene from the object's point of view). One clear break beats three timid ones.

## Hard limits (not options)

No provocation may do any of these, however clever:

- No celebrity or real person's likeness.
- No health claims.
- Nothing that offends on food, children or religion.
- Competitors only as an archetype or a category cliche, never a named rival, and a human legal review is flagged whenever the work jabs at the category's rivals.

## Staying true to the brand

- The provocation is built **on the idea platform**. It may break how the platform is expressed. It may not contradict what the platform and the messaging house say.
- The brand's claims list, banned words, regulator rules and never-do list stay in force exactly as written. The brand's usual tone is the thing being departed from, so it is not a limit here.
- The brand's own mechanic should still be recognisable in the break. A provocation that could be signed by anyone has failed.

## Good sparks

A spark is one specific idea, written in a sentence or two, that names the code it breaks. It is concrete (a film with no people in it, not "be bolder"), it can be made in a 30 second film and travels to at least one other medium, and it says what stays true. Offer a real spread: some that break one code gently, some that break several, at least one that changes who or what is on screen.

## Developing one

Develop the chosen spark into: a name; the provocation in one line; the codes it breaks; the stance (tone, humour, structure); a **risk** label (low, medium or high) with the honest reason; a **safer version** that keeps the idea but keeps more of the category's comfort; what it becomes in each medium (one clear line each); and, for the film, the structure, humour, visual language, sound language, cast approach (people, objects, animated or none), voiceover length in words, and how the brand arrives.

Risk is judged on how far it departs and how much a wrong reading would cost the brand: **low** departs in one code and is easy to read as a brand choice; **medium** breaks a major code; **high** could be misread as the brand not caring, as mockery, or as breaking a hard limit's spirit. Say why.

## Pushing further

"Push it further" makes the break bolder in the direction asked while keeping every limit and the platform's truth. The version being pushed becomes the **safer version**, so the person never loses it.

**What:** opt-in checkbox "Land the music's lift on the turn" under the Tempo/Dynamics chips (state `musicOnTurn`, default OFF, session state like those controls; sent as `music_on_turn` by `produceVideo`, `rescoreCut` and the shared `voicePayload` = preview; NOT by the Edit-room cutdown paths). Backend: `filmaudio.bed_lift_time()` (0.25 s energy windows; compares the 2 s after each point with the 2 s before; ignores jumps out of silence; needs ≥3 dB) + `_align_bed()` (moves the bed so its strongest lift lands on the turn; ≤4 s shift; refuses and says why when no clear rise / too far / bed too short to start later / lift already within 0.4 s); called by BOTH `_preview_audio_once` and `_mix_timeline_once` right after the bed download so preview == render; `turn_at=None` default on all four functions so every other caller (incl. `/cut-sound`) is untouched. The turn's real start: the render adds up beats of SURVIVING shots before the first `turn` role; re-score + preview use `main._turn_at_from_rows` (scene_seconds → plan_by_scene → roles) — verified identical (22.0 s for a 6-scene 30 s film). Shift>0 delays the bed (fades in first, then delays); shift<0 skips ahead with `-ss`. Notes appear in the usual mix notes/`detail`.
**Verified:** synthetic bed with a lift planted at 7.0 s → found 7.0 s (+20 dB), flat tone → none; REAL `mix_timeline` output with `turn_at=10` moves the lift in the mixed film audio 7.25 s → 10.25 s (OFF stays 7.25 s); `preview_audio` agrees; refusal cases leave the bed untouched; routes pass `turn_at` correctly / None when off; py_compile -W error, selfcheck, checkfe, repo wiring test, smoke. **NOT verified:** how it sounds on a REAL generated bed — all tests used synthetic tones.
